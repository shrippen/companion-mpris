Companion
MPRIS

Control MPRIS-capable media players on Linux from Bitfocus Companion over D-Bus. Spotify, VLC, Firefox, Chrome, Rhythmbox, Feishin — no playerctl needed.

Steuere MPRIS-fähige Mediaplayer unter Linux aus Bitfocus Companion über D-Bus. Spotify, VLC, Firefox, Chrome, Rhythmbox, Feishin – ohne playerctl.

1. Download the .tgz from the latest release.
2. In Companion open Settings → Modules → Import module package.
3. Under Connections → Add connection search for “MPRIS”.

1. Lade das .tgz aus dem neuesten Release herunter.
2. Öffne in Companion Settings → Modules → Import module package.
3. Suche unter Connections → Add connection nach „MPRIS“.

Actions

Transport actions

Transport-Aktionen

Play/Pause, Play, Pause, Stop, Next track and Previous track.

Play/Pause, Play, Pause, Stop, nächster Titel und vorheriger Titel.

Auto

Auto player selection

Automatische Playerwahl

Every action has a Player dropdown. Auto picks the playing player, or the first one found. Target a specific player when several run at once.

Jede Aktion hat ein Player-Dropdown. Auto wählt den laufenden Player oder den ersten gefundenen. Bei mehreren Playern lässt sich ein bestimmter gezielt ansteuern.

Feedback

Playback feedback

Wiedergabe-Feedback

Colors a button depending on whether the selected player is Playing, Paused or Stopped.

Färbt eine Taste je nachdem, ob der gewählte Player spielt, pausiert oder gestoppt ist.

Presets

Ready-made presets

Fertige Presets

Kategorie MPRIS Transport Controls: Play/Pause mit Live-Feedback, Previous, Next, Stop, Play, Pause. Per Drag-and-drop auf eine Taste ziehen.

D-Bus

Pure JS, no playerctl

Reines JS, kein playerctl

Talks to MPRIS directly via dbus-next. Falls back to $XDG_RUNTIME_DIR/bus when Companion starts the module without a session bus address.

Spricht MPRIS direkt über dbus-next. Fällt auf $XDG_RUNTIME_DIR/bus zurück, wenn Companion das Modul ohne Session-Bus-Adresse startet.

On your buttons

Auf deinen Tasten

Drag the presets onto a Companion page and you get transport keys that react to the player. Play/Pause changes its color with the playback status, and the variables put the current title, artist or album on any button.

Ziehe die Presets auf eine Companion-Seite, und du bekommst Transporttasten, die auf den Player reagieren. Play/Pause ändert seine Farbe mit dem Wiedergabestatus, und die Variablen zeigen aktuellen Titel, Künstler oder Album auf jeder Taste.

  • Use variable references like $(LABEL:track_title) in a button text, where LABEL is the name of your MPRIS connection
  • Pick Auto in the Player dropdown so the keys follow whichever player is playing
  • Pin a key to one player when several run at once
  • Nutze Variablenverweise wie $(LABEL:track_title) im Tastentext, wobei LABEL der Name deiner MPRIS-Verbindung ist
  • Wähle Auto im Player-Dropdown, damit die Tasten dem gerade spielenden Player folgen
  • Lege eine Taste auf einen Player fest, wenn mehrere gleichzeitig laufen

Installation

Installation

  1. Download the .tgz from the Releases page.
  2. In Companion open Settings → Modules → Import module package and select the file.
  3. Under Connections → Add connection search for “MPRIS” and add it. No configuration required.
  1. Lade das .tgz von der Releases-Seite herunter.
  2. Öffne in Companion Settings → Modules → Import module package und wähle die Datei.
  3. Suche unter Connections → Add connection nach „MPRIS“ und füge es hinzu. Keine Konfiguration nötig.

Run from source

Aus dem Quellcode

For development. The packaged release above is the easy way.

Für die Entwicklung. Das fertige Release oben ist der einfache Weg.

git clone https://github.com/shrippen/companion-mpris.git ~/companion-dev/mpris cd ~/companion-dev/mpris && npm install
  1. Clone the repo into a subfolder of a development folder, e.g. ~/companion-dev/mpris.
  2. Run npm install inside the module folder.
  3. In the Companion launcher set Developer modules path to the parent folder, not the module folder.
  4. Restart Companion and add the “MPRIS” connection.
  1. Klone das Repo in einen Unterordner eines Entwicklungsordners, z. B. ~/companion-dev/mpris.
  2. Führe npm install im Modulordner aus.
  3. Setze im Companion-Launcher den Developer modules path auf den übergeordneten Ordner, nicht auf den Modulordner.
  4. Starte Companion neu und füge die Verbindung „MPRIS“ hinzu.

Requirements

Voraussetzungen

  • Linux with a running D-Bus session bus (standard on any desktop session)
  • One or more MPRIS-capable players, e.g. Spotify or VLC
  • Node.js 22+ (bundled with Companion; install separately for local testing)
  • Linux mit laufendem D-Bus-Session-Bus (Standard in jeder Desktop-Sitzung)
  • Ein oder mehrere MPRIS-fähige Player, z. B. Spotify oder VLC
  • Node.js 22+ (in Companion enthalten; für lokale Tests separat installieren)
