# Changelog

The release notes of Companion MPRIS, newest first. Each section is the text of the release on Gitea
and GitHub and of its entry in `#changes` on the landing page (`docs/index.html`).

## [1.0.0] — 2026-09-14

### English

The first release: control MPRIS media players on Linux (Spotify, VLC, Firefox, Feishin, …) from Bitfocus Companion.

#### New
- Actions Play/Pause, Play, Pause, Stop, Next and Previous, each with a choice of player.
- A feedback that colours a button by playback status (playing, paused, stopped), and variables with the current track.
- Ready-made presets: drag them onto a Companion page and get transport keys that react to the player.

#### Note
- Install: download `generic-mpris-1.0.0.tgz` from the release, then in Companion go to Settings → Modules → Import module package and select the file.

### Deutsch

Die erste Version: MPRIS-Mediaplayer unter Linux (Spotify, VLC, Firefox, Feishin, …) aus Bitfocus Companion steuern.

#### Neu
- Aktionen Play/Pause, Play, Pause, Stop, Weiter und Zurück, jede mit Wahl des Players.
- Ein Feedback, das eine Taste nach Wiedergabestatus färbt (spielt, pausiert, gestoppt), und Variablen mit dem aktuellen Titel.
- Fertige Presets: auf eine Companion-Seite ziehen und Transporttasten bekommen, die auf den Player reagieren.

#### Hinweis
- Installation: `generic-mpris-1.0.0.tgz` vom Release laden, dann in Companion unter Settings → Modules → Import module package die Datei wählen.
